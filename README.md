# 🩺 Doctor Appointment Website

A simple, responsive web app for booking doctor appointments online. Built with plain **HTML, CSS and JavaScript**, with no frameworks and no build tools.



Live link :-https://himesh-07.github.io/hello-doctor/





---

## ✨ Features

- Browse the list of available doctors
- Search and filter doctors by name or specialty
- Book an appointment by choosing a date and time slot
- Form validation for name, phone, email and date
- Appointment confirmation message
- View and cancel your booked appointments
- Data saved in the browser using `localStorage`
- Fully responsive for mobile, tablet and desktop

## 🚀 Getting Started

No installation needed.

**1. Clone the repository**

```bash
git clone https://github.com/himesh-07/doctor-appointment.git
```

**2. Open the project folder**

```bash
cd doctor-appointment
```

**3. Run it**

Double-click `index.html`, or use the **Live Server** extension in VS Code.

---

## 📖 How to Use

1. Open the website and browse the doctors.
2. Click **Book Appointment** on a doctor.
3. Fill in your details and pick a date and time.
4. Submit the form to get a confirmation.
